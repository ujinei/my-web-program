알바 급여 매니저

1. 프로그램 소개
알바 급여 매니저는 아르바이트 근무 내역을 등록하고 총 근무시간과 예상 급여를 간편하게 확인할 수 있는 웹 프로그램입니다.

2. 주요 기능
- 시급 설정 및 저장
- 근무 날짜 등록
- 출근 시간과 퇴근 시간 입력
- 근무 내역 등록 및 조회
- 총 근무일수 확인
- 총 근무시간 계산
- 총 예상 급여 계산
- 개별 근무 내역 삭제
- 자정을 넘기는 야간 근무시간 계산

3. 사용 방법
1. 프로그램을 실행합니다.
2. 원하는 시급을 설정합니다.
3. 근무 날짜를 선택합니다.
4. 출근 시간과 퇴근 시간을 입력합니다.
5. 근무 내역 등록 버튼을 누릅니다.
6. 등록된 근무 내역과 총 근무시간, 예상 급여를 확인합니다.
7. 필요하지 않은 근무 내역은 삭제할 수 있습니다.

4. 개발 환경
- HTML5
- CSS3
- JavaScript
- Safari 웹 브라우저

5. 제작 목적
아르바이트 근무시간과 예상 급여를 직접 관리할 수 있는 프로그램을 제작하면서 HTML, CSS, JavaScript의 활용 방법을 익히고 웹 프로그램 제작 과정을 이해하는 것을 목적으로 합니다.
